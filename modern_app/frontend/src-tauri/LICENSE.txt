ScisoNomics es una aplicación de escritorio orientada a la gestión financiera personal. La aplicación permite al usuario cargar, organizar y visualizar información financiera propia, incluyendo movimientos, ingresos, gastos, categorías, presupuestos, planificación, estadísticas, backups y datos asociados a su cuenta.

ScisoNomics puede funcionar con datos almacenados localmente en el dispositivo del usuario y, cuando el usuario utiliza una cuenta cloud o funciones de sincronización, puede sincronizar determinados datos con servidores externos para permitir respaldo, recuperación o uso entre dispositivos.
